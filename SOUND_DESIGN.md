# Звуковой дизайн

Игра уже содержит оригинальные синтезированные плейсхолдеры и полностью работает без дополнительных файлов.

## Файлы

Заменять нужно файлы в `src/assets/audio`, сохраняя имена и формат WAV:

| Файл | Где звучит | Желаемый характер |
| --- | --- | --- |
| `ui-click.wav` | кнопки и HUD | мягкий стеклянный тик, 50–100 мс |
| `card-select.wav` | выбор героини и манга-кадра | воздушный magical select |
| `battle-hit.wav` | удар по минус вайбу | плотный fantasy impact без оружейного реализма |
| `achievement-unlock.wav` | новое достижение | короткий редкий loot/advancement reveal |
| `scene-complete.wav` | завершение главы | тёплый трёхнотный resolve |
| `cat-purr.wav` | найденная кошка | короткое лицензированное мурчание |
| `circuit-connect.wav` | узел схемы | energy node connect / crystal circuit |
| `room-soften.wav` | действие заботы | мягкий room tone bloom |
| `finale.wav` | комната доказательств | камерный эмоциональный reveal |

## Референсы

- Достижение: ощущение редкой игровой ачивки, но без копирования Minecraft, Xbox или PlayStation.
- Draft: сочетание anime RPG character select и мягкого MOBA feedback.
- Схема: кристаллическое соединение узлов, не sci-fi laser.
- Финал: короткий эмоциональный подъём в духе финальной сцены фильма, без узнаваемой мелодии.

Не вставляйте звук непосредственно из фильма или игры без отдельной лицензии. После покупки исходника обрежьте его до указанного события, нормализуйте без клиппинга и экспортируйте в WAV 44.1 kHz.

## Где искать лицензируемые варианты

- BOOM Library: профессиональные UI, magic и cinematic packs.
- Sonniss: игровые аудиобиблиотеки и ежегодные GDC bundles.
- Artlist: лицензируемые cinematic и fantasy SFX.
- Pixabay: бесплатные звуки, но лицензию конкретного файла всё равно нужно проверить и сохранить.

После замены выполните:

```bash
npm run build
npm run build:flash
```
